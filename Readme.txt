Options:

[Very Low]: Denoisers and SSR are disabled

[Default]: Stable shadows and reflections

[Normal]: More shadows and better AO. Astral Vision's Sharp Shadows and optional Volumetric Clouds

[High]: Enabled Nanite for pop-in issues on modern GPUs. Degrades performance on older cards

[Very High]: Enabled Lumen and Nanite with full clarity optimizations


Presets:

[TAA]: Temporal Anti-Aliasing optimizations. Minimized temporal effects

[TSR]: Temporal Super Resolution optimizations. Max clarity with removed TAA effects

[Astral Shadows]: Sharp Shadows unique to Astral Vision.

[Astral Clouds]: Aion 2 hidden clouds. Big boost in performance on older cards

[Volumetric Clouds]: Default clouds.


Recommendations:
If the game is too sharp and you prefer default smoothness, use the following in-game settings:
-Upscaler: TAA

If the game is still too sharp for you, use the following in-game settings:
-Post-Processing Quality: VeryLow

If shadows are too sharp/crisp/pixelated, use the following Mod preset:
-Default Shadows

If you want the default clouds back, use the following Mod preset:
-Volumetric Clouds

If you lost frames/performance, use the following Mod option:
-Normal


Aion 2 Recommended in-game settings:

[Resolution Scale]: Native

[Effect Quality]: VeryLow - Low

[Shadow Quality]: VeryLow - Low - Normal

[Shading Quality]: VeryLow - Low

[Post-Processing Quality]: VeryLow

[Upscaler]: TSR - FSR - DLSS - XESS

- If you want more sharpness, set Post-Processing Quality: Low
- Use in-game Accessibility -> Visual Assist -> White Point Reduction setting to reduce light sensitivity
